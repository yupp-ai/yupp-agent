# Sample workspace

This is a tiny markdown tree used by the `ahs-memory` test suite and by
operators kicking the tires manually. It's a generic personal-notes
layout (a top-level `README.md`, a `notes/` folder, a `projects/`
folder, a hidden dotfile that must be skipped, a non-`.md` file that
must be skipped) — the same structure works for any Markdown
workspace you'd want to mirror into AHS memory.
